# Customer Satisfaction (CSAT) Analytics Dashboard
## Project Overview
This project is an interactive Power BI dashboard designed to analyze Customer Satisfaction (CSAT) data. The dashboard helps organizations monitor customer support performance, identify trends, and improve decision-making through visual analytics.
---
## Objectives
- Monitor customer satisfaction (CSAT)
- Analyze customer call trends
- Identify reasons for customer calls
- Evaluate response time and call duration
- Analyze customer sentiment
- Explore state-wise customer interactions
---
## Dashboard Features
### KPI Cards
- Total Calls
- Average CSAT Score
- Average Response Time
- Average Call Duration
### Interactive Filters
- Date
- Channel
- State
- Sentiment
### Visualizations
- Call Volume Trend Over Time
- Calls by Channel
- Calls by Reason
- Calls by Response Time
- Customer Sentiment Distribution
---
## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX
- Power Query
---
## Dataset
The dataset contains customer support information including:
- Customer Name
- Call Date
- State
- Channel
- Reason for Call
- Response Time
- Call Duration
- Sentiment
- CSAT Score
---
## Key Insights
- Phone is the primary customer support channel.
- Positive sentiment accounts for the largest share of customer feedback.
- Query is the most common reason for customer calls.
- Customer calls fluctuate over time, indicating seasonal trends.
- Interactive filters allow users to analyze data dynamically.
